# my-tools

A weekly **Tool Scout**: a Claude Code routine that runs every Monday at 07:00
(America/Sao_Paulo), searches the web for new dev, AI and desktop tools that fit
my stack, and emails me 5 picks plus 1 wildcard.

| File | What it is |
|------|------------|
| [`stack.md`](stack.md) | What I use, what I care about, what's out of scope. The routine never recommends anything listed here. |
| [`history.md`](history.md) | Every tool recommended so far, with my rating. Used to avoid repeats. |
| [`ROUTINE.md`](ROUTINE.md) | The routine's full instructions. Edit this to change its behavior; the routine itself only says "follow ROUTINE.md". |

**Feedback:** reply to the Monday email with `1 ✅ 2 👀 4 ❌` (adopted / will try /
not for me), or free text such as "I also use X" or "less AI stuff". The next
run reads the reply and updates `stack.md` and `history.md`.
